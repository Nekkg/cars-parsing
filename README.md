# Cars Parser

Приложение для поиска автомобильных объявлений на Avito, Auto.ru и Дроме.
Сайт и Telegram-бот используют общие фильтры, каталог, базу объявлений и очередь
сбора. Сайт написан на Django, JavaScript и CSS.

## Быстрый запуск

Для демонстрации лабораторной работы используйте **Python 3.14**.
Распакуйте проект или скачайте репозиторий и откройте терминал в его корне:

```console
python -m pip install -c requirements-lock.txt -e .
python -m core.cli web
```

Откройте http://127.0.0.1:8000. Команда создаст локальную базу SQLite,
применит миграции и запустит сайт со сборщиком. Docker, PostgreSQL и Telegram-токен
для этого запуска не нужны. На Windows с несколькими Python используйте
`py -3.14` вместо `python` в обеих командах.

Для установки зависимостей и поиска нужен интернет. Для Auto.ru установите
Google Chrome. При первом обращении Selenium может загрузить подходящий драйвер.
Новая база пуста: выберите марку и модель и запустите поиск. Ранее собранные
объявления и пользовательские настройки не входят в репозиторий.

Для изоляции зависимостей можно предварительно создать виртуальное окружение:
`python -m venv .venv` и активировать его обычным для вашей системы способом.
Готовую папку окружения с другого компьютера переносить не следует.

## Отдельные процессы и настройки

```console
python -m core.cli web --no-collect
python -m core.cli --env .env bot
python -m core.cli collect
```

Первая команда запускает только сайт с сохранёнными данными. Вторая запускает
бота, третья — отдельный сборщик. Если команда `web` уже запущена со сборщиком,
второй сборщик для той же локальной SQLite не требуется.

Для бота скопируйте [.env.example](.env.example) в локальный `.env` и задайте
`TELEGRAM_BOT_TOKEN`. Для сайта этот файл необязателен. Параметры PostgreSQL,
прокси и удалённого Selenium приведены в `.env.example`. Значения токенов,
прокси, cookies и сеансы браузера должны оставаться локальными.

Порядок выбора настроек: явно указанный `--env`, затем `.env` в корне проекта,
затем старый `reference-parser-daa/.env`, если корневого файла нет. Эти файлы
не смешиваются. Переменные, заданные в терминале, имеют приоритет над файлом.
После изменения `.env` перезапустите сервер. Для прямого подключения оставьте
`SOURCES_PROXY_URL=` пустым; для Avito его отдельный маршрут задаёт `AVITO_PROXY_URL`.

## Возможности

- Общий поиск и фильтры марки, модели, поколения, цены, года, города и характеристик.
- Выбор площадки, сортировка, страницы, сетка и список объявлений на сайте.
- Подробная карточка, галерея и отображение на узком экране.
- Уменьшенные фотографии, локальный кеш и сообщения при ошибках загрузки.
- Поиск, карточки и «Уведомления» в Telegram.
- Сохранение объявлений, поисковых задач и очереди уведомлений в базе.

## Проверки

На Python 3.14.7 прошли **457 автоматизированных тестов**. Проверены поиск,
фильтры, сортировка, переходы по страницам, галерея и мобильный вид в Chrome.
Через сайт успешно получены **114 из 114 основных превью** проверенной выборки.
Выполнены реальные запросы к Дрому и Auto.ru. При повторной проверке Avito
23.11.2026 получены две страницы для каждого из запросов Kia, Audi и BMW:
в локальной базе сохранены 292 разных объявления. После проверки безопасности
Avito вернул HTTP 200; сессия сохранена локально для повторного запуска.
Это результат конкретной проверки: доступность внешнего сайта может меняться.
Доставка Telegram через использованный локальный прокси не подтверждена.
Эти ограничения не подменяются результатами модульных тестов.

```console
python reference-parser-daa/manage.py test tests --noinput
```

## Структура проекта

Исходный код находится в `reference-parser-daa/`: `ads` — сайт и общий поиск,
`bot` — Telegram, `parsers` — сбор, `users` — фильтры и уведомления,
`core` — настройки и команды запуска, `tests` — тесты.
Локальная база, кеш и журналы создаются в `runtime/` и исключены из Git.

Docker остаётся дополнительным способом развёртывания. Его настройки находятся в
`reference-parser-daa/docker-compose.yml`. Для лабораторной демонстрации
используйте команды локального запуска выше. При публикации сайта в интернете
потребуются отдельный сервер приложения, HTTPS и настройка статики.
