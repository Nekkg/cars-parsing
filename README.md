# Cars Parser

Telegram-бот для поиска автомобилей на Avito, Auto.ru и Дроме. Общая база
PostgreSQL, объявления с фотографиями, фильтры и уведомления.

При сортировке «Новые» первая подборка содержит по одной самой свежей подходящей
машине в порядке Avito → Auto.ru → Дром. Далее кнопка «Ещё 3 машины» выдаёт
оставшиеся объявления из общей базы по новизне без повторов. «Дешевле» и «Дороже»
сортируют всю выдачу по цене. Недоступная площадка или отсутствие подтверждённых
совпадений сокращают первую подборку; машины вне фильтра не подставляются.

Новизна определяется датой публикации/обновления, если площадка её предоставляет,
иначе — первым появлением в базе. Повторный сбор не меняет дату появления.
Статус отдельно показывает обработанные записи и подходящие машины: обновления
существующих записей, неподходящие поколения и непроверенные карточки не увеличивают
число результатов. Явные обозначения поколений (например, I и P24) сопоставляются
внутри модели; одного года выпуска для подтверждения поколения недостаточно.

Поколения нормализуются по общему каталогу для всех марок и моделей: коды кузова,
исходные обозначения площадок и рестайлинги сопоставляются с единым идентификатором.
Каталог выбранной модели загружается автоматически и кешируется. Неоднозначные
поколения сохраняются без догадок. [Подробнее и команды обновления](docs/GENERATIONS.md).

## Структура

- `reference-parser-daa/bot/` — Telegram-бот.
- `reference-parser-daa/ads/` — объявления, фильтры и каталог машин.
- `reference-parser-daa/parsers/` — сборщики и общий кеш запросов.
- `reference-parser-daa/core/` — настройки и сетевые подключения.
- `reference-parser-daa/tests/` — тесты; `scripts/` — служебные команды.
- `docs/` — инструкции. Локальные данные в `runtime/` исключены из Git.

## Запуск

Нужны Docker Desktop и заполненный локальный `.env`. Если Telegram использует
Karing, оставьте его включённым. Команды выполняются из `reference-parser-daa/`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\configure-avito-route.ps1 -Node msk -NoRestart
docker compose up -d db chrome_driver
docker compose build bot parsers
docker compose run --rm --no-deps parsers python manage.py migrate
docker compose up -d bot parsers
```

В боте откройте «Фильтры» и задайте автомобиль. Сбор работает в фоне.
Повторный запуск: `docker compose up -d`; остановка: `docker compose stop`.

[Первый запуск](docs/LOCAL_RUN.md) · [Avito](docs/AVITO.md) · [Сеть](docs/NETWORK.md).
Avito использует HTTP-сессию с локальными проверками PoW/GeeTest; доступ зависит от ответа
площадки. Selenium нужен для Auto.ru. Redis и десктопный браузер не используются.
Веб-код сохранён, веб-сервис исключён из обычного запуска.
Токены, пароли и cookies хранятся локально. [Лицензия](reference-parser-daa/LICENSE).
