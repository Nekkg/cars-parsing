# Cars Parser

Telegram-бот и веб-поиск автомобилей на Avito, Auto.ru и Дроме. Общая база
PostgreSQL, объявления с фотографиями, фильтры и уведомления.

Выдача — одна карточка с фотографией. Стрелки листают автомобили в том же
сообщении, кнопки площадок переключают Avito / Auto.ru / Дром / все источники.
«Списком» открывает отдельное сообщение по 10 объявлений с пагинацией. Доступны
галерея фотографий, обновление и «Следить». Можно сохранить несколько запросов,
выбрать частоту 1/2/5/10/30 минут и управлять ими через «Отслеживание».
Кнопки сортировки и статуса сбора скрыты; их функционал сохранён.
Найденные в фоне объявления автоматически
пополняют выдачу со счётчиками и сообщениями о добавлении по площадкам.
При сортировке «Новые» первые три позиции — самая свежая подходящая машина
каждой доступной площадки в порядке Avito → Auto.ru → Дром, затем общая выдача.
«Дешевле» и «Дороже» сортируют всю выдачу по цене.

В «Фильтрах» можно написать запрос одной строкой:
`солярис 2017–2020 до 1.2 млн казань +200`. Распознаются русские названия,
коды кузова, год/диапазон лет, цена, город, радиус и другие условия.
Неполный запрос предлагает варианты. [Возможности и примеры](docs/BOT_SEARCH.md).

Новизна определяется датой публикации/обновления, если площадка её предоставляет,
иначе — первым появлением в базе. Повторный сбор не меняет дату появления.
Статус отдельно показывает обработанные записи и подходящие машины: обновления
существующих записей, неподходящие поколения и непроверенные карточки не увеличивают
число результатов. Явные обозначения поколений (например, I и P24) сопоставляются
внутри модели; одного года выпуска для подтверждения поколения недостаточно.

Поколения нормализуются по общему каталогу для всех марок и моделей: коды кузова,
исходные обозначения площадок и рестайлинги сопоставляются с единым идентификатором.
Каталог выбранной модели загружается автоматически и кешируется. Неоднозначные
поколения сохраняются без догадок. [Подробнее и команды обновления](docs/GENERATIONS.md).

Проверка сейчас ограничена 49 распространёнными моделями из 16 марок. Общая
очередь сохраняет ссылку на подтверждённое объявление и результат загрузки фото. [Отчёты и команды](docs/VEHICLE_AUDIT.md).

## Веб-поиск

Откройте http://localhost:8000. Сайт использует общую базу и очередь парсеров
Telegram-бота. Можно написать `бмв x5 2015–2018 самара +200 до 4 млн` или задать
марку, модель, несколько поколений, город, радиус до 1000 км, цену и годы отдельно
«от» / «до», пробег и владельцев, двигатель, коробку, привод, кузов, цвет, руль,
состояние, продавца и модификацию. Дополнительные параметры — в «Все фильтры»;
в группах можно выбрать несколько значений. Подсказки понимают русские
названия и опечатки. Площадки переключаются без нового сбора; доступны сортировка,
карточки / список, страницы и галерея. Новые результаты подгружаются автоматически.

Запускайте из **`cars-parser/reference-parser-daa`** при включённом Docker Desktop:

```powershell
docker compose --profile web --profile avito-proxy build web bot parsers
docker compose --profile web --profile avito-proxy up -d db chrome_driver avito_proxy
docker compose --profile web run --rm --no-deps web python manage.py migrate --noinput
docker compose --profile web --profile avito-proxy up -d web bot parsers
```

Повторный запуск: последняя команда. Остановить только сайт: `docker compose --profile web stop web`.
Сбор веб-запроса активен 30 минут; кнопка «Обновить» продлевает сбор. Вкладка
опрашивает результаты раз в 5 секунд во время сбора и раз в 20 секунд после него.
Скрытая вкладка не опрашивает сервис. Одинаковые запросы разных пользователей
используют одну задачу сбора; фильтры браузеров изолированы сессиями.

Сайт доступен только на этом ПК. Домен и регистрация не нужны. Это локальный
запуск Django (`runserver --insecure` для локальной статики); перед публикацией
нужен отдельный сервер приложения, HTTPS и конфигурация статики. Разрешённые
хосты задаются `DJANGO_ALLOWED_HOSTS`, доверенные внешние origins —
`DJANGO_CSRF_TRUSTED_ORIGINS`, секреты остаются в `.env`.

Количество в выдаче — подходящие объявления, а не все обработанные парсером.
Если площадка ограничивает доступ, её статус отображается отдельно; найденные
ранее машины остаются в базе. Радиус использует координаты городов из локального
справочника; адреса без однозначно определённого города не включаются в радиус.

[Устройство веб-поиска и проверки](docs/WEB_SEARCH.md).
## Структура

- `reference-parser-daa/bot/` — Telegram-бот.
- `reference-parser-daa/ads/` — объявления, фильтры и каталог машин.
- `reference-parser-daa/parsers/` — сборщики и общий кеш запросов.
- `reference-parser-daa/core/` — настройки и сетевые подключения.
- `reference-parser-daa/tests/` — тесты; `scripts/` — служебные команды.
- `docs/` — инструкции. Локальные данные в `runtime/` исключены из Git.

## Запуск

Нужны Docker Desktop и заполненный локальный `.env`. Если Telegram использует
Karing, оставьте его включённым. Команды выполняются из `reference-parser-daa/`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\configure-avito-route.ps1 -Node msk -NoRestart
docker compose up -d db chrome_driver
docker compose build bot parsers
docker compose run --rm --no-deps parsers python manage.py migrate
docker compose up -d bot parsers
```

В боте: `/start` → «Найти машину». Для изменения условий используйте «Фильтры». Сбор работает в фоне.
Повторный запуск: `docker compose up -d`; остановка: `docker compose stop`.
После замены токена в локальном `.env` пересоздайте бот: `docker compose up -d --force-recreate --no-deps bot`.

[Первый запуск](docs/LOCAL_RUN.md) · [Avito](docs/AVITO.md) · [Сеть](docs/NETWORK.md).
Avito использует HTTP-сессию с локальными проверками PoW/GeeTest; доступ зависит от ответа
площадки. Selenium нужен для Auto.ru. Redis и десктопный браузер не используются.
Веб-сервис включается отдельно профилем `web`, адрес http://localhost:8000.
Токены, пароли и cookies хранятся локально. [Лицензия](reference-parser-daa/LICENSE).
