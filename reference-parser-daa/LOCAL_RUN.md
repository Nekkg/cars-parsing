# Локальный запуск

Откройте Docker Desktop и Karing, дождитесь их запуска. Команды выполняйте в этой папке.
Раздельные маршруты Telegram и площадок описаны в [NETWORK.md](NETWORK.md).

Первый запуск:

```powershell
docker compose up -d db redis chrome_driver
docker compose build
docker compose run --rm web python manage.py migrate
docker compose run --rm web python manage.py setup_local
docker compose up -d
```

Повторный запуск:

```powershell
docker compose up -d
```

Остановка с сохранением базы:

```powershell
docker compose stop
```

Состояние и логи:

```powershell
docker compose ps
docker compose logs --tail 50 bot parsers
```

Сайт: http://localhost:8000/

Админка: http://localhost:8000/admin/

Логин: значение DJANGO_SUPERUSER_USERNAME в .env (по умолчанию admin).
Пароль: значение DJANGO_SUPERUSER_PASSWORD в .env.
setup_local создает администратора только при его отсутствии, существующий пароль не меняет.

В Telegram: /start, затем /car BMW → модель → поколение.
Основной сценарий: «Фильтры» → написать `bmw 3` или `bmw m340 2018` →
подтвердить модель и выбрать поколение либо «Искать без поколения».
Год в текстовом запросе означает точный год выпуска. M340 сохраняется как
модификация: объявления остальных 3-Series не подменяют её.
«Очистить выбор» сбрасывает условия и выключает уведомления. После нового выбора
уведомления можно включить отдельной кнопкой в постоянном меню или в фильтрах.
Команды /notifications_on и /notifications_off управляют уведомлениями;
старые /monitor_on и /monitor_off оставлены как совместимые псевдонимы.

Сайт заморожен по просьбе владельца. Ссылки и команда перехода на него убраны из
интерфейса бота; не дорабатывать сайт до отдельного запроса (см. AGENTS.md).
Git remote исходного проекта удалён. История и лицензия сохранены; новый remote
нужно будет добавить только после создания владельцем собственного репозитория.
Первым открывается подборка популярных марок; «Все марки» открывает полный каталог.
Во время выбора можно отправить название сообщением: `бмв`, `ауд`, `toytoa`.
После выбора марки текст ищет модели, после модели — поколения.
Редкие марки доступны через общий поиск и полный список; записи из базы не удаляются.
Порядок подборки редактируется в ads/catalog_search.py (POPULAR); это настройка
интерфейса, а не статистический рейтинг продаж.
/filters — дополнительные условия, /search — запустить сбор,
/results — сохранённые результаты, /status — состояние каждого источника.
/monitor_on — включить отслеживание.
Остановка уведомлений: /monitor_off.

Бот показывает по 3 объявления с основным фото, новые загрузки первыми.
Кнопка «Ещё 3» сохраняет порядок текущей выдачи, «Обновить» добавляет новые результаты.
Все выбранные площадки попадают в общий список, который сортируется целиком:
«Новые» (по времени загрузки в базу), «Дешевле» или «Дороже». Сортировка сохраняется.
Первый показ ожидает ответа выбранных площадок; после минуты ожидания доступны
частичные результаты. Количество машин каждого источника видно под выдачей.
Истёкшие браузерные сессии пересоздаются автоматически с повтором прерванной загрузки.
В цене можно независимо задать «от» и «до», введя сумму или «нет» для удаления границы.
Ранее введённое одиночное число цены трактуется как верхняя граница бюджета.

Сбор проходит страницы до конца доступной выдачи или ограничения площадки.
SEARCH_MAX_PAGES — предохранительный предел страниц на город/марку (по умолчанию 500,
допустимо 1–1000); достижение предела видно в статусе. SEARCH_INTERVAL_SECONDS —
интервал мониторинга (по умолчанию 300 секунд). Новый ручной запрос начинает сбор
без ожидания этого интервала, кроме паузы после блокировки площадки.
Города из меню, цена и год передаются в запросы к поддерживающим их площадкам.
Для произвольного города без известного адреса остаётся поиск по стране с местной
фильтрацией; это медленнее. Отдельные обозначения моделей площадок тоже могут отличаться.
Недоступные площадки, удалённые объявления и закрытые данные не входят в гарантированное
покрытие. Каталог марок, моделей
и поколений загружается с Дрома по запросу и кешируется локально.

Адрес localhost открывается на том ПК, где работает проект. На телефоне открывайте
самого бота; локальный сайт на телефоне по этому адресу недоступен.

Источники включаются и выключаются в разделе парсеров Django-админки.
Запущенный контейнер парсера сам по себе не гарантирует получение объявлений:
ошибки загрузки сайтов и капчи смотрите в логах.

Не публикуйте .env и необработанные логи. Не используйте down -v, если хотите сохранить базу.
