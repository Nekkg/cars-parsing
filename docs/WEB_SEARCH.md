# Веб-поиск

Рабочая папка: `cars-parser/reference-parser-daa`. Локальный сайт: http://localhost:8000.
Команды запуска приведены в корневом README. Профиль `web` сохраняет возможность
запускать только Telegram-бота. Сетевая конфигурация парсеров общая для обоих клиентов.

## Общая логика

- `ads/vehicle_query.py` — разбор русского запроса для сайта и бота. Использует
  `query_language`, `text_query`, общий каталог и его приоритеты.
- `ads/filter_schema.py` — общие варианты фильтров и нормализация характеристик
  площадок: АКПП/автоматическая, AWD/полный, джип/SUV, ё/е, состояния и продавцы.
- `ads/forms.py` — проверка полей сайта, привязка города к локальным координатам,
  открытые числовые границы, проверка принадлежности поколений модели.
- `ads/search.py` — общий снимок фильтров, fingerprint задачи, SQL-предфильтрация
  и точная проверка объявления. Поколения выбираются по каталогу; сборщики получают
  соответствующие годы, а окончательная проверка не угадывает неизвестное поколение.
- `WebSearch` — отдельная сессия браузера с FK на общий `SearchJob`. Коллектор
  выбирает такие задачи наравне с активными запросами Telegram. Новый запрос
  завершает прежний сбор только в этом браузере, не затрагивая других пользователей.
- `ads/web_search.py` — безопасная выдача, сортировка, страницы по 18 машин,
  общий кеш идентификаторов/счётчиков на 3 секунды для всех площадок и сортировок. Фотографии загружаются только
  для текущей страницы. Автомобили разных площадок не склеиваются по похожему названию.
- `ads/views.py`, `templates/`, `static/ads/` — API и адаптивный интерфейс без CDN.

Выбор площадки и сортировка меняют представление общей выдачи и не запускают
дублирующий сбор. Данные постепенно дополняются из всех выбранных площадок;
браузер показывает прибавление подходящих объявлений по каждой площадке.
Начальная выдача включает уже сохранённые подходящие машины, пока идёт новый сбор.

## Фильтры и интерфейс

Марка, модель и несколько поколений; модификация; город и радиус до 1000 км;
цена, годы, пробег и число владельцев с независимыми границами «от» / «до»;
двигатель, коробка, привод, кузов, цвет, руль, состояние, продавец, площадки.
Варианты в группах объединяются по «или», разные группы — по «и».
Неизвестная характеристика не удовлетворяет явно выбранному ограничению.
«Битый» не совпадает с «не битый»; синонимы площадок нормализуются одинаково
в Telegram и вебе. Дополнительные цвета можно написать через запятую.

Основные параметры остаются в боковой панели, остальные доступны в «Все фильтры».
На телефоне прокручивается содержимое диалога, кнопка применения остаётся видимой.
Ошибки границ показываются внутри окна, выбор сохраняется после перезагрузки.
Справочник городов имеет ограниченный кеш подсказок; каталог переиспользуется
в браузере. При паузе источника показано время повтора, без обещания активного сбора.

Avito получает город и поддерживаемый радиус в собственных параметрах
`localPriority`, `radius`, `searchRadius`. Проверка расстояния в общей базе остаётся
обязательной. При неподдерживаемом городе сохраняется общий поиск и местная
проверка; Auto.ru/Дром при радиусе продолжают существующий общий сбор.
Старый курсор Avito без геофильтра начинается с первой страницы нового запроса;
сохранённые объявления и очередь уточнения не удаляются.

## API

Все изменения выполняются POST с CSRF; API работает в той же сессии, что сайт.

- `GET /catalog/?parent=…&q=…` — марки / модели / поколения, популярные сначала.
- `GET /api/cities/?q=…` — города с регионом и идентификатором, включая мск / спб.
- `POST /api/query/` — `{ "text": "солярис 2017–2020 казань +200 до 1.2 млн" }`.
- `POST /api/searches/` — проверенные поля формы → первоначальная общая выдача.
- `GET /api/searches/<uuid>/?platform=all&sort=newest&page=1` — результаты и статусы.
  Сортировки: `newest`, `cheap`, `expensive`; площадки: `all`, `avito`, `autoru`, `drom`.
- `POST /api/searches/<uuid>/refresh/` — продлить сбор на 30 минут. Общая очередь
  объединяет запросы и не перезапускает уже работающий сбор.

Чужая или отсутствующая сессия получает 404 для сохранённого поиска. Идентификатор
сам по себе не даёт доступа. Клиенту не передаются cookies, proxy URL, сырые ошибки
Selenium и внутренние очереди карточек. Ссылки и фотографии ограничены доменами
выбранной площадки. Веб-API не принимает произвольный адрес для загрузки сервером.

## Проверки

```powershell
docker compose exec -T web python manage.py check
docker compose exec -T web python manage.py makemigrations --check --dry-run
docker compose exec -T web python manage.py test tests --noinput
docker compose exec -T web python scripts/check-web-ui.py
```

`tests/ads/test_web_search.py` проверяет совпадение с фильтрами бота, радиус,
несколько поколений, частичное пополнение, сортировку, страницы, включение в очередь,
изоляцию браузеров, CSRF и отсутствие внутренних данных в ответах. Для визуальной
проверки `scripts/check-web-ui.py` запускает отдельную Selenium-сессию:
русский запрос, площадки, сортировку, карточки/список, несколько поколений,
все расширенные фильтры, валидацию, восстановление после перезагрузки,
мобильный диалог и очистку. Снимки сохраняются локально в `runtime/diagnostics/`.
Тест требует запущенных `web`, `db`, `chrome_driver` и наполненного каталога/базы.

`tests/ads/test_filter_parity.py` проверяет общие характеристики, все опции бота,
открытые границы и разбор дополнительных условий текстом; тесты радиуса Avito —
`tests/parsers/test_avito_radius.py`. Не нужны новые миграции для этих фильтров.

Локальная разработка не гарантирует доступ площадок: ограничения источника
показываются в его статусе. Обложка/галерея могут отсутствовать в неполной карточке
или если сама площадка не отдаёт фотографию браузеру.

ошибок JavaScript и горизонтального переполнения нет. Отдельно проверены

и статусом «готово»; [подробности и ограничения](AVITO.md).

## Начальная лента

При первом открытии сайта без сохранённого запроса показываются объявления из
общей базы, сначала свежие, по 18 на страницу. Площадки, сортировка, фотографии,
галерея и страницы доступны сразу. `GET /api/feed/` читает базу с пагинацией в SQL;
счётчики площадок кешируются на 3 секунды. Этот просмотр не создаёт SearchJob,
WebSearch или задачи сбора. «Обновить» перечитывает сохранённые объявления.
После задания условий используется обычный поиск с фоновым сбором; сохранённый
поиск по-прежнему восстанавливается при перезагрузке страницы.
