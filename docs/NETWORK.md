# Сетевые подключения

Описание основано на `core/network.py`, `parsers/avito_client.py` и служебных скриптах. Текущие порты, сеть, Karing и площадки во время документирования 9–10 октября 2026 года не проверялись.

| Клиент | Явная настройка |
| --- | --- |
| Telegram | `TELEGRAM_PROXY_URL`, отдельная AiohttpSession |
| Avito | `AVITO_PROXY_URL`: пустая строка — прямой выход; отсутствующая переменная допускает `SOURCES_PROXY_URL` |
| Auto.ru, Дром, каталог и загрузка фотографий | `SOURCES_PROXY_URL`; каталог urllib требует HTTP-маршрут |

Системные переменные proxy не подменяют явный маршрут HTTP-клиента. В Docker обращение к Windows использует `host.docker.internal`; `127.0.0.1` относится к самому контейнеру. Историческая настройка Karing предполагала отдельные локальные порты; их доступность не устанавливается этим документом.

После изменения `.env` пересоздайте соответствующий процесс, например:

```powershell
docker compose up -d --force-recreate --no-deps bot parsers
```

Не передавайте `.env`, полный вывод Compose config, cookies или session JSON в публичные журналы. HTTP 200 не доказывает извлечение автомобилей: Avito может вернуть проверку или SSR-редирект. `SourceBlocked` не всегда означает доказанную блокировку IP.

## Российский маршрут Avito

`scripts/configure-avito-route.ps1` рассчитан на собственный существующий VLESS-узел Karing. Он копирует выбранную настройку в закрытый `runtime/sessions/avito-proxy.json`, ограничивает права, включает профиль `avito-proxy` и изменяет локальное окружение. Telegram остаётся на отдельном маршруте; активный узел Karing не переключается. Скрипт предполагает прямой порт Karing 3065 и внутренний порт sing-box 3068 — эти значения являются особенностями реализации, не результатом текущей проверки.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\configure-avito-route.ps1 -Node msk -ProxyUrl "http://PROXY_HOST:PROXY_PORT" -NoRestart
```

Альтернатива — `-Node spb`, если такой собственный узел существует. Подготовленный контейнер запускается `docker compose --profile avito-proxy up -d avito_proxy`; при необходимости сайт добавляется профилем `web`. Прокси-порт не публикуется на ПК. Другой собственный HTTP-прокси записывает `scripts/set-avito-proxy.ps1`.

## Диагностика и исторические файлы

В этом рабочем каталоге физически присутствуют `scripts/diagnostics/check_network.py` и `check_avito_browser.py`, но каталог `diagnostics/` исключён `.gitignore`; эти локальные файлы не входят в текущую поставку Git. На другой копии их может не быть. Они выполняют реальные запросы к Telegram/площадкам, а браузерная проверка создаёт диагностические артефакты. Во время документирования не запускались.

Актуальные воспроизводимые инструкции — [DEVELOPMENT.md](DEVELOPMENT.md), HTTP-путь Avito — [PARSERS.md](PARSERS.md). Django `manage.py check` проверяет систему Django, но не подтверждает сетевую доступность источников. Служебный noVNC-порт 7900 относится к Selenium; его доступность в текущей среде не проверена.
