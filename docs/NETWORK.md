# Сетевые подключения

Каждый клиент явно выбирает маршрут из локального `.env`:

| Назначение | Настройка |
| --- | --- |
| Telegram | `TELEGRAM_PROXY_URL` — VPN-прокси Karing |
| Avito | `AVITO_PROXY_URL` — отдельный HTTP/SOCKS-прокси; пустое значение означает прямой выход |
| Auto.ru, Дром, фотографии | `SOURCES_PROXY_URL` |

На этом ПК прямой порт Karing — `3065`, VPN-порт — `3066`. В Docker вместо
`127.0.0.1` используется `host.docker.internal`. Системные переменные прокси не
подменяют явный маршрут Avito. Karing должен работать, пока используются его порты.

После изменения `.env`:

```powershell
docker compose up -d --force-recreate bot parsers
```

Проверка Telegram и источников без вывода токенов:

```powershell
docker compose exec -T bot python -m scripts.diagnostics.check_network
```

HTTP 200 сам по себе не доказывает наличие объявлений. Avito может вернуть
перенаправление внутри HTML или страницу проверки. Его HTTP-клиент сохраняет
одну сессию и проходит поддерживаемую PoW-проверку локально. Ограничение IP
остаётся отдельной причиной отказа; при блокировке сборщик делает паузу.
Порт `7900` относится к Selenium Auto.ru. Локального помощника Chrome нет.
## Российский маршрут Avito

Для локального демо используется ваш существующий узел Karing «Россия МСК».
Один Docker-контейнер `avito_proxy` обслуживает общий сборщик, а не отдельного
пользователя. Порт прокси не опубликован на ПК и доступен только в сети проекта.
Telegram продолжает использовать текущий VPN-выход Karing.

Однократная настройка / обновление после изменения подписки Karing:

```powershell
cd reference-parser-daa
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\configure-avito-route.ps1 -Node msk
```

Альтернатива в вашей подписке: `-Node spb`. Скрипт копирует только выбранный
собственный VLESS-узел в закрытый файл `runtime/sessions/avito-proxy.json` и
включает профиль Compose `avito-proxy`. Karing и его активный узел не переключаются.
Файл содержит VPN-реквизиты: он исключён из Git и ограничен правами пользователя
и SYSTEM. Не публикуйте этот файл.

Соединение Docker с RU-узлом идёт через прямой порт Karing `3065`. Это нужно
потому, что прямой выход Docker на этом ПК отличается от выхода Windows.
В `.env` для Avito устанавливается `AVITO_PROXY_URL=http://avito_proxy:3068`.
Оставьте Karing включённым. При обычном `docker compose up -d` прокси запускается
вместе с проектом; временных процессов Windows для него не требуется.
