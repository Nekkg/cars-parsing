# Проверка марок и моделей

Текущий прогон ограничен 49 моделями из 16 марок — по одному подтверждённому объявлению
на Avito, Auto.ru и Дроме (147 проверок). Остальные проверки отложены, их результаты сохранены. Проверка идёт по всей России, без города, поколения,
года и цены: дополнительные ограничения могут скрыть единственную машину.
Наличие объявлений для каждой редкой или исторической модели не гарантируется.

## Что считается подтверждением

`confirmed` означает: прочитана поисковая выдача, открыта карточка, модель совпала
с запросом, основная фотография скачана и обработана, объявление сохранено в
общей базе и проходит тот же фильтр, что используется ботом. Если карточка
публикует canonical/og:url, дополнительно проверяется её идентификатор.
Объявление может быть снято продавцом после проверки; время проверки есть в отчёте.

Названия и URL Auto.ru сверяются с его публичным каталогом. Составные марки,
альтернативные названия и варианты внутри общих семейств нормализуются в общих
сборщиках. Например, Mazda3/3, Honda Stepwgn/Stepwagon, Evoque/Range Rover Evoque,
Infiniti FX35 внутри раздела FX. Saab 93 и 9-3, Freed и Freed+ сохраняют различие.
Неоднозначные варианты не подтверждаются по догадке. Для Lexus на Avito точный индекс читается из поля «Модификация»: заголовок RX/NX/LX не смешивает разные моторные версии. Обозначение Avito «NX 200 2.0t» сопоставляется с NX200t, а не с атмосферной NX200. Подсказки из объёма и коробки лишь упорядочивают кандидатов аудита; подтверждение требует точного индекса в карточке.

## Отчёты

В `reference-parser-daa/runtime/reports/`:

- `vehicle-audit-by-model.csv` — одна строка на модель, результат и ссылка отдельно
  для каждой площадки; удобно открыть в Excel.
- `vehicle-audit.csv` — подробная таблица проверок, время, цена, число фото.
- `vehicle-audit.json` — итоговые счётчики, подробные доказательства и ошибки.
- `catalogue-consistency.json` — отдельная проверка распознавания названий.

Живые отчёты обновляются примерно раз в минуту при продвижении очереди.
`makes_without_models` перечисляет марки, для которых не удалось получить модели;
они не выдаются за проверенные. После остановки Docker отчёт остаётся снимком.

| Статус | Значение |
|---|---|
| `confirmed` | Реальное объявление, карточка и фото подтверждены |
| `empty` | Площадка явно сообщила об отсутствии предложений на первой странице |
| `no_matching_model` | Прочитана выдача, но выбранная модель в ней не подтверждена |
| `unverified_card` | Кандидаты есть, но карточка, характеристики или фото не подтвердились |
| `blocked` | Площадка ограничила доступ; это не пустая выдача |
| `error` | Ошибка чтения, сети или адреса раздела; требуется проверка |
| `pending` | Проверка ещё не выполнена или ожидает освобождения общего запроса |
| `deferred` | Проверка вне текущего ограниченного набора; результат не удалён |

`no_matching_model` и `unverified_card` не означают, что машин на площадке нет.
Проверяются первая страница и до трёх подходящих карточек. Кеши прочитанных
страниц действуют до пяти минут; обычные поиски и аудит используют общий доступ.
В отчётах нет cookies, токенов, паролей прокси и идентификаторов пользователей.

## Запуск и повторение

Команды выполняются из `reference-parser-daa/`, когда запущены Docker и бот:

```powershell
# Справочники: загрузить недостающие модели и точные разделы Auto.ru.
docker compose exec -T bot python manage.py sync_source_names --expand-catalog

# Проверить распознавание всех названий без запросов к площадкам.
docker compose exec -T bot python manage.py check_vehicle_names

# Подготовить очередь. Повтор команды не сбрасывает уже проверенные строки.
docker compose exec -T bot python manage.py audit_vehicles --popular --prepare --report

# Полный каталог можно явно вернуть позднее: audit_vehicles --all-models --prepare

# Получить свежий снимок результатов в любой момент.
docker compose exec -T bot python manage.py audit_vehicles --report

# Повторить ошибки после исправления. Подтверждённые и пустые строки сохраняются.
docker compose exec -T bot python manage.py audit_vehicles --retry-failed
```

Очередь и результаты находятся в PostgreSQL и переживают перезапуск. Проверки
выполняются существующими тремя сборщиками: дополнительного браузера на модель
или пользователя нет. Сохранённая форма без открытой выдачи не продолжает сбор дольше часа после запроса. Открытые карточки продлевают сбор; отслеживание и старые включённые уведомления работают независимо от этого срока.

Новые запросы пользователей и загрузка их фотографий
приоритетнее аудита. В свободное время проверка идёт постоянно; во время старого
полного сбора — не чаще одной модели в минуту на площадку. Между запросами
проверка уступает очередь новому поиску.

При ограничении доступа действует пауза 15 минут для всей площадки. Повтор
неудачных проверок не отменяет эту паузу. HTTP 5xx на служебном этапе Avito отмечается как ошибка сервера, с паузой аудита на минуту, без статуса ограничения доступа для пользовательских запросов. Остальные площадки продолжают работу.
Пока Docker выключен, проверки не идут. Telegram не получает тестовых сообщений.
Веб-версия в этом процессе не запускается и не изменяется.

Успех проверки названий означает согласованность справочника. Он **не означает**,
что URL доступен, объявление есть или все площадки прошли живую проверку — это
показывает только отдельный живой отчёт.
Набор задаётся в `parsers/audit_scope.py`: BMW, Audi, Mercedes-Benz, Toyota,
Volkswagen, Lada, Kia, Hyundai, Nissan, Honda, Lexus, Skoda, Volvo, Haval, Chery,
Geely. Это выбранный набор для демо, а не статистический рейтинг продаж.
`audit-scope.json` сохраняет активные модели; обычный `--report` показывает только
их. `--all-models` возвращает отложенную очередь, сохраняя подтверждения.
